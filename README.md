# GIABA instalable (Abalauquen)

La app de Abalauquen para instalar en el celu (un solo ícono; cada uno baja solo su parte).
Primera sección: **Ferias** (cobrar, total, cerrar; anda sin señal).

- No tiene ningún secreto: la clave pública de la base llega con el pase al entrar con el PIN.
- El código fuente vive en el repo privado `Abalauquen/GIABA` (carpeta `pwa/`) y se copia acá para publicarlo con GitHub Pages.
